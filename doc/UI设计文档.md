## 1. 设计目标

- **高效收发**：三栏布局（文件夹 / 邮件列表 / 邮件详情），与主流邮件客户端一致，降低学习成本。
- **实时感知**：WebSocket 实时推送新邮件，未读角标即时更新。
- **离线可用**：PWA 可安装、离线浏览已同步邮件与已缓存附件。
- **简洁克制**：信息分层清晰，留白充足，可读性强；支持浅/深主题。
- **可访问性**：对比度、键盘导航、ARIA 标签符合基础规范。

## 1.1 规范引用

- 色彩 / 字体 / 间距 / 圆角 / 阴影 / 动效：使用《UI设计规范.md》第 2 章设计令牌。
- 通用组件（按钮 / 表单 / 表格 / 弹层 / Tag / Badge / Empty 等）：使用《UI设计规范.md》第 4 章。
- 可访问性与响应式：使用《UI设计规范.md》第 6、3 章。

## 4. 页面详细设计

### 4.1 登录页 `/login`

```
+--------------------------------------------------+
|  [Logo]  邮箱客户端                                |
|  用户名  [____________]                            |
|  密码    [____________]                            |
|  [记住我]  [忘记密码]                              |
|  [ 登录 ]（主色，满宽）                            |
|  没有账号？[注册]                                  |
+--------------------------------------------------+
```
- 中央卡片式，最大宽度 400px。
- 登录成功后跳转 `/mail`。
- 错误提示内联显示（红色）。
- OAuth 按钮（若启用）：Google/Microsoft（可选）。

### 4.2 主界面（三栏）`/mail`

```
+----------------+------------------+------------------------------+
| 文件夹栏       | 邮件列表         | 邮件详情（可收叠）           |
| [发件] 按钮    | 搜索 [____]  ☰图标|                              |
| -收件箱   (5)  | +--- 发件人 主题 ------- 日期   ⭐  |              |
| -星标         | | A先生  周报       2024-01-01  ⭐  |  主题/发件人   |
| -草稿    (2)  | | B先生  会议通知     2024-01-02      |  时间         |
| -已发送       | | C先生  发票附件     2024-01-03      | ------------  |
| -已删除       | +----------------------------------+  正文(清洗后)  |
| -垃圾箱       |                                    |  附件列表      |
| + 自定义文件夹|                                    |              |
+----------------+----------------------------------+--------------+
```

**文件夹栏**
- 新建文件夹（树形展开/收起），右键菜单（重命名/删除/移动到）。
- 未读数红色圆角徽标。

**邮件列表**
- 每行：发件人头像/发件人、主题、预览、日期、星标、附件图标。
- 未读：加粗+左侧主色竖条；已读：普通。勾选支持批量操作（标记已读/删除/移动）。
- 顶部工具条：刷新、批量勾选、筛选（未读/星标）、排序。
- 下拉到底自动加载更多/分页。
- 实时：新邮件推送到当前文件夹时顶部插入并更新未读数，轻提示。

**邮件详情**
- 头部：主题、发件人、时间、收件人、操作按钮（回复/全部回复/转发/标记/删除/打印）。
- 正文：HTML 已清洗渲染；文本回退。
- 附件区：图标卡（名称/大小/下载/预览）。
- 支持上一封/下一封切换。

### 4.3 写邮件（Compose）

- 触发：主界面「发件」→ 抽屉/新版面。
- 字段：收件人（多选 tags)、抄送/密送（可展开）、主题、富文本正文（工具栏：加粗/斜体/列表/链接/图片）、附件上传。
- 草稿 30s 自动保存（右上角"已保存 HH:mm"状态）。
- 发送按钮、附件图标、格式切换（富文本/纯文本）。
- 附件上传可拖拽，显示进度与大小校验。

### 4.4 设置-账户 `/settings/accounts`

```
账户管理
[+ 添加账户]
- Gmail  alice@gmail.com   IMAP · 正常    [管理][设为默认][删除]
- QQ邮箱 alice@qq.com      IMAP · 正常    [管理][删除]
```
- 添加账户向导：输入邮箱 → 自动探测 → 选择协议/加密 → 凭据(应用密码/授权码/OAuth) → 连接测试 → 完成。

### 4.5 设置-规则 `/settings/rules`

```
规则列表            [ + 新建规则 ][排序]
# 名称            条件               动作            状态
1 老板邮件        发件人含 boss      移入"重要"       [开][编辑][×]
2 含发票附件      含附件            打星 + 标记已读    [开][编辑][×]
```
- 新建规则编辑器：
  - 条件（且/或，可多组）：发件人/收件人/主题/正文/大小/附件。
  - 动作：移动到文件夹/标记已读/打星/删除/转发。
  - 优先级拖动排序，启停开关。
- 规则命中可实时弹提示（可选）。

### 4.6 导入导出 `/export`

```
数据迁移
[选择文件 .pst] [开始导入]      (限制≤100MB)
  导入进度条 / 结果提示
导出
[ 目标文件夹: 收件箱 ▾ ] [导出为 .pst]
  导出为异步任务，完成后提供下载
```

### 4.7 管理后台 `/admin`（管理员）

- 用户列表/搜索/禁用。
- 配额设置（每用户容量与附件存储方式）。
- 审计日志查看/筛选。
- 系统状态（在线数、推送延迟、存储占用）。

## 6. 关键交互流程

### 6.1 登录
`/login` → 校验 → 存取 token → 建 WS 连接 → 跳 `/mail` → 拉文件夹+未读数。

### 6.2 实时到件
服务端推 `MAIL_NEW` → 前端更新对应文件夹未读数 → 若在当前文件夹，插入列表顶部 + 顶部 Toast。

### 6.3 写邮件
点「发件」→ ComposeDialog → 输入 → 草稿自动保存(30s) → 发送 POST /messages → 成功 Toast → 关闭 → 已发送更新。

### 6.4 添加账户
设置-账户 → 添加 → 输入邮箱 → auto-detect 填表 → 填凭据 → 连接测试 → 保存 → 开始首次同步。

### 6.5 规则编排
设置-规则 → 新建/编辑 → 条件+动作 → 保存 → 优先级排序 → 启用；命中实时生效。

### 6.6 PST 导出
导出页 → 选文件夹 → 导出 → 异步任务进度 → 完成后下载 → 用 Outlook 验证读取。

## 7. 响应式与离线

### 7.1 响应式断点

| 断点 | 行为 |
| --- | --- |
| ≥ 1024px | 三栏完整 |
| 768~1023px | 邮件列表/详情切换标签，保留文件夹栏 |
| < 768px | 单栏移动布局；列表与详情互切；发件为全屏页 |

### 7.2 PWA / 离线

- **vite-plugin-pwa**：自动生成 manifest + Service Worker（Workbox）。
- 预缓存：静态资源、应用外壳。
- 运行时缓存：已读取邮件详情、已打开附件（indexedDB / Cache Storage）。
- 离线状态栏提示；在线自动同步增量并刷新。
- 后台离线队列：离线发送的邮件缓存在队列，联网后补发。

## 8. 可访问性（a11y）

- 键盘：Tab 有序聚焦，方向键列表导航，快捷键（N 新建 / R 回复 / F 转发 / 空格翻页）。
- 对比度：文本与背景 ≥ 4.5:1；状态不只依赖颜色（未读同时用加粗与竖条）。
- ARIA：弹窗 role=dialog，实时通知 aria-live=polite，树 aria-tree。
- 语义化标签：header/nav/main/section/button/a。

### 10.3 已实现的交互功能

- **文件夹切换**：点击左侧文件夹动态切换列表数据与未读数。
- **邮件列表**：点击行查看详情、点击星标切换、复选框**批量操作**（已读/删除/移动）、全选、实时搜索、仅看未读、分页。
- **登录/注册**：表单必填校验与错误信息展示。
- **写邮件**：选择发件账户、添加/移除附件、发送校验、自动保存提示。
- **添加账户向导**：邮箱地址 → 服务器**探测演示**（IMAP/POP3/SMTP + 加密）+ 连接测试动画 → 成功。
- **规则管理**：新建/编辑规则的条件-动作编辑器弹层。
- **PST 导入导出**：导入进度条动画、导出进度 + 生成可下载 .pst（Outlook 可读）。
- **全局反馈**：Toast 通知（成功/信息/危险）。

### 10.4 已落实的规范要素

- 设计令牌（语义色 / 中性色 / 字体 / 间距 / 圆角 / 阴影 / 动效）集中以 CSS 变量定义，并内置浅/深两套主题。
- 深色主题通过 `@media (prefers-color-scheme: dark)` 自动跟随系统。
- 通用组件（按钮 / 输入 / 卡片 / Tag / Badge / 表格 / 分页 / 空状态 / Skeleton / Toast）按基础规范第 4 章样式。
- 未读状态采用「加粗 + 主色强调」而非仅靠颜色，符合 a11y。
- 邮件详情正文为安全渲染示意（`white-space:pre-wrap` 文本，无 HTML 注入渲染）。

### 10.5 响应式

- `≥1024px`：完整三栏布局。
- `768–1023px`：收拢为两栏（隐藏详情，点列表行进入）。
- `<768px`：单栏移动布局，文件夹栏与详情自动收进抽屉/全屏（原型以隐藏示意，开发态用抽屉实现）。

### 10.6 后续开发映射

原型中的 CSS 令牌将迁移为全局样式文件（如 `frontend/src/styles/tokens.css`），组件对齐《UI设计规范.md》第 4 章，页面映射到 Vue 路由（见第 3.1 节），交互逻辑迁移到 Pinia store 与 Composition API。
