## 1. 目标与环境

### 1.1 目标

依据已确认的需求分析与详细设计，落地一套**可运行**的多用户 Web 邮箱客户端：

- 每用户独立 OST 工作存储文件
- 兼容主流邮件收发协议 IMAP4 / POP3 / SMTP 及常见加密（SSL / STARTTLS / NONE）
- 支持文件夹、邮件规则
- 支持导入 / 导出 **PST**（导出产物供 Outlook 打开读取，单向）
- 实时推送（IMAP IDLE + WebSocket），降级轮询
- 附件本地 + MinIO 双存储（可切换）
- PWA 离线访问
- Spring Boot 3 + Vue 3 前后端分离

## 3. 后端设计落地要点（对照详设）

- 鉴权：JWT(HS256) + Spring Security 过滤器；`CurrentUser` 上下文；BCrypt 密码；凭据 AES-256-GCM。
- 邮件：`MailClient` 接口（IMAP/POP3 实现，com.sun.mail）→ `MailService`；`SyncWorker` 账户级线程做 IDLE + UID 增量。
- OST：每用户文件布局 + 文件锁 + 元数据外置到 MySQL（v1 简化：正文入 MySQL，附件入存储介质）。
- 规则：`RuleEngine` 按 priority 评估 conditions → actions；`Ruler` 动作接口。
- 推送：`/ws` WebSocket，握手用 JWT query 参数；`PushService` 发布事件。
- 附件：`AttachmentStorage` 接口 → `LocalFileStorage` / `MinioStorage`，配置切换。
- 统一返回 `{code,message,data}`；统一异常 `GlobalExceptionHandler`。

## 4. 前端设计落地要点（对照 UI 设计文档）

- 路由：`/login` `/mail` `/mail/folder/:id` `/mail/message/:id` `/settings/accounts` `/settings/rules` `/settings/general` `/transfer` `/admin`。
- 三栏工作台：文件夹树 / 邮件列表（虚拟滚动、搜索、筛选、分页）/ 详情（HTML 清洗后渲染）。
- 写邮件：富文本（contenteditable 封装，v1 存 HTML）、附件、草稿自动保存。
- Pinia store：`auth / accounts / folders / mails / rules / ui`。
- axios 拦截器注入 JWT、统一错误提示；WebSocket 客户端接收推送事件。
- PWA：vite-plugin-pwa + Workbox，缓存静态资源与已读摘要，离线提示。
- 设计令牌：迁移自《UI设计规范.md》，见 `frontend/src/styles/tokens.css`。

## 6. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 真实外部邮箱联调受限 | 提供本地 mock IMAP/SMTP 或枚举型接口，接口契约一致，可后续替换 |
| PST 库兼容性 | 使用成熟 Java 库，导出逻辑隔离为 `PstExporter` 便于替换 |
| 构建工具在本会话不可运行验证 | 代码遵循详设与标准结构，交付配套 DDL 与启动文档，确保评审可构建 |
| 前端构建体积 | 按需引入 Element Plus，Tree-shaking |
